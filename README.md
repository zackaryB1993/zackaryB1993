## What I've built

At [SendSafely](https://www.sendsafely.com/), an end-to-end encrypted file transfer platform:

- **Actions**: a serverless workflow engine on AWS Lambda that lets customers plug their own antivirus and DLP scanning into the platform through HMAC-signed webhooks. Designed and built as the sole engineer; live in US, EU, and AU.
- **MCP Server**: lets AI assistants such as Claude list, inspect, and manage encrypted packages. A local server that encrypts on the user's machine, and a stateless remote connector that only ever sees metadata.
- **OAuth 2.1 Authorization Server**: a standalone microservice with PKCE, token exchange, rotating refresh tokens, and KMS-signed tokens, wired into the platform API with per-endpoint scope enforcement.
- **Custom Form Builder**: an AI assistant on Amazon Bedrock AgentCore that turns a chat description into a hosted secure intake form.

Earlier, at Delta Air Lines: the payment engine behind delta.com checkout and the backend for paying with eCredits, eCertificates, and Gift Cards.

On the side: **PQVault**, a post-quantum encrypted password manager (Rust, Tauri, React Native), in development.

Each of these has an interactive architecture diagram on the [portfolio](https://zackaryb1993.github.io/#work).
